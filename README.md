# JSON 格式化与对比

自用的纯前端 JSON 工具。页面只保留格式化与对比两个入口，初始内容为空，直接粘贴接口返回值使用。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。静态部署使用 `npm run build`，将 `dist/` 放到任意静态 HTTP 服务中；不要直接用 `file://` 打开，浏览器会限制模块和 Worker。

## 功能

- CodeMirror 6 编辑器：语法高亮、折叠、查找替换、撤销、行号。
- 严格 JSON 校验与错误定位，支持 2 / 4 / 8 空格格式化及压缩。三个代码区均支持左键双击格式化，也可使用按钮或快捷键。
- 格式化、压缩和对比保留原始数字精度，包括超大整数。
- 树形视图按需展开、全部展开、字段 / 值 / 路径搜索，双击定位代码。
- 输入暂停 350 ms 后自动对比，无需点击开始；修改数组选项也会重算。默认忽略对象键序，数组按索引；可选忽略数组顺序（多重集合匹配，保留重复项数量）。
- 两侧代码区双向同步滚动。不同长度文档按滚动比例联动；点击差异时保留各侧精确位置。
- 差异筛选、路径搜索、点击定位两侧代码、导出完整差异报告。
- 复制、下载、清空和撤销。无工作空间、文档管理、示例或文件导入入口。
- 内容仅在内存中，刷新或关闭后清空；存在未导出更改时尝试触发浏览器离开提醒。

## 大文档设计与边界

编辑器、树形和差异列表只渲染可见区域。解析、格式化、树形生成与对比在 Web Worker 中运行。自动对比一次仅处理一个任务，连续输入合并为最新一次；过期结果或错误不会覆盖新内容。

对比模式的大文档同样自动处理；格式化模式超过 250 KB 的内容按需解析，可双击格式化、手动校验或进入树形视图。嵌套上限 512 层。

十万行不是固定字节数，真实速度受数据结构、字符长度和设备内存影响。浏览器仍需持有原始文档和解析树，大段粘贴/整篇替换存在主线程分配成本。

无序数组中的未匹配元素显示为删除与新增，不做相似项猜测。新建或移除的对象/数组作为一条差异显示，可点击定位完整内容。重复键允许校验和格式化，但提示其存在，并拒绝对比以避免含糊结果。

差异报告的 `beforeJSON` / `afterJSON` 是对应节点的原始 JSON 文本字符串（节点不存在时为 `null`），因此导出不会损坏大整数。

## 核心验证

```sh
npm test
```

覆盖自动对比防抖、过期结果与错误隔离、无效输入恢复、数组选项重算、语法校验、数值精度、特殊路径、重复字段，以及 120,002 行样本的格式化、全量树形和结构对比。

## 技术

原生 JavaScript + Vite + [CodeMirror 6](https://codemirror.net/docs/guide/) + [jsonc-parser](https://github.com/microsoft/node-jsonc-parser)。运行依赖全部打包到静态产物。
