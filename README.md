# JSON 格式化与对比

自用的 JSON 工具。编辑、搜索和对比在浏览器本地运行，分享功能使用 Vercel Functions 与 Upstash Redis。页面只保留编辑器与对比两个入口，初始内容为空，直接粘贴接口返回值使用。

## 在线试用

**[打开 JSON 工作台](https://json.aiworld.cool/)** · [使用指南与常见问题](https://json.aiworld.cool/guide.html) · 无需注册或登录，打开即可使用。

在「编辑器」中粘贴 JSON，即可格式化、校验、搜索并查看结构图；切换到「对比」，粘贴两份 JSON 后会自动列出结构差异。

平时的 JSON 编辑、搜索和对比仅在浏览器本地处理。只有点击「分享」时，当前内容才会上传保存 7 天并生成链接。对方打开的是独立副本，可正常编辑、格式化、搜索和对比，修改不会影响分享者或原链接；再次分享会创建新的副本。刷新或关闭页面前，请复制或下载本地修改。

生产版本使用 Vercel Web Analytics 统计访客与页面浏览量，不采集 JSON 内容、搜索词或分享 ID；上报前移除页面地址中的查询参数和 hash。本地开发不启用访问统计。

## 搜索与 AI 可发现性

首页的应用元信息、页头和帮助说明直接写入 HTML；`public/guide.html` 提供无需 JavaScript 的使用说明、示例与数据处理说明。`public/robots.txt` 开放公开页面抓取并排除 `/api/`，`public/sitemap.xml` 只列出首页和指南。分享 API 保留 `X-Robots-Tag: noindex, nofollow`，分享内容不进入站点地图。更换正式域名或新增公开页面时，同步更新这些文件中的 canonical、结构化数据和站点地图。上线后可将站点地图提交到 Google Search Console 与 Bing Webmaster Tools，并观察收录和引用数据。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。静态部署使用 `npm run build`，将 `dist/` 放到任意静态 HTTP 服务中；不要直接用 `file://` 打开，浏览器会限制模块和 Worker。

### 分享功能

编辑器右上角「分享」生成短链接，点击「复制链接」发送给同事。无需登录，持有链接的人均可访问。链接保存的是点击时的 JSON 原文，保留大整数、重复字段与转义；7 天后由 Redis 自动删除。普通编辑不会上传，也不会自动保存到分享链接。

Vercel 部署时，连接一个 Upstash Redis 数据库，并配置服务端环境变量 `KV_REST_API_URL` 与 `KV_REST_API_TOKEN`（也支持 Upstash 的 `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`）。项目根目录的 `api/share.js` 负责创建和读取分享；无需额外路由配置。凭据不要加 `VITE_` 前缀，不得提交到 Git。开发时将变量写入被忽略的 `.env.local`，`npm run dev` 会运行同一接口。

分享单份上限 4 MiB；超过时请先压缩或拆分，编辑器本身不受此限制。为保护免费额度，同一来源每小时最多创建 20 次，全站每日最多 200 份 / 24 MiB；超额只暂停新建，不覆盖已有分享。页面和接口均不缓存分享响应，不提供修改原分享的接口。匿名链接不是权限管理，请只分享适合发送给同事的内容。

仅部署 `dist/` 的静态站点仍可使用全部本地功能，但不能创建或读取分享链接。

## 功能

- 全站采用 [Dracula Theme Official](https://github.com/dracula/visual-studio-code/blob/main/src/dracula.yml) 配色：灰紫背景、粉紫强调与深色状态栏，字段青色、字符串黄色、数值及布尔值紫色；代码编辑器、结构图、缩略图、搜索浮层与对比页保持一致的语法配色和清晰选区。
- CodeMirror 6 编辑器：语法高亮、折叠、撤销、行号。代码右侧提供可收起/展开的缩略图，显示视口范围，支持点击、拖动、滚轮及方向键/Page Up/Page Down/Home/End 导航。局部预览显示搜索命中行，最右侧标记栏显示全文命中位置，点击标记可跳转。
- 严格 JSON 校验与错误定位，支持 2 / 4 / 8 空格格式化及压缩。三个代码区均支持单行对象/数组 JSON 左键双击格式化；多行内容双击正常选词，灰紫选区清晰可见，可用 ⌘ / Ctrl + C 复制。任意排版也可通过按钮或快捷键格式化。
- 格式化、压缩和对比保留原始数字精度，包括超大整数。
- 代码与基于 [React Flow](https://reactflow.dev/) 的完整节点结构图同屏显示，分栏宽度可拖动调整；图无分页和节点数量截断，支持平移、缩放、展开/收起，随光标自动定位具体 key。缩小为概览时显示节点轮廓，点击缩放百分比恢复原始大小并定位当前字段。
- 结构图字段及卡片标题显示 TypeScript 类型标签，如 `string`、`number`、`boolean`、`null`、`object`、`string[]` 和混合数组联合类型。根据当前值概括所有直接数组元素，空数组为 `unknown[]`，多维数组的内层概括为 `unknown[]`，不展开对象类型声明。长标签悬停查看完整类型，点击仍定位代码；这些标签不代表完整 Schema 或接口类型约束。
- 全局搜索字段 / 值，不受图中位置或折叠状态限制。关键词仅匹配字段名或值本身，不因祖先路径包含关键词而列出子项；输入完整路径可精确查找该项。结果以搜索框下方浮层显示，点击结果后收起；Esc、关闭按钮或点击外部也可收起，保留关键词和缩略图标记，再次点击搜索框或搜索按钮展开。结果列表显示匹配内容、含数组下标的 JSON 路径与行号，点击跳转并展开被折叠的代码和图分支。代码区同步高亮所有实际命中的关键字，当前结果加粗边框；中文与 JSON 转义按原文位置标记，完整路径查找标记对应字段。关闭浮层保留高亮，清空搜索或编辑 JSON 时清除旧范围。⌘ / Ctrl + F 聚焦搜索，Enter / Shift + Enter 切换结果。
- 当前位置栏跟随光标更新，一级字段也显示 `$.key`；字段行的缩进、值末尾和逗号后仍显示该字段路径。支持复制完整路径和在图中定位。带空格、点号或其他特殊字符的字段使用方括号表示，如 `$.fields[2].props["校验.规则"].max`。
- 输入暂停 350 ms 后自动对比，无需点击开始；修改数组选项也会重算。默认忽略对象键序，数组按索引；可选忽略数组顺序（多重集合匹配，保留重复项数量）。
- 两侧代码区双向同步滚动。不同长度文档按滚动比例联动；点击差异时保留各侧精确位置。
- 差异筛选、路径搜索、点击定位两侧代码、导出完整差异报告。
- **工具菜单**（编辑器工具栏「工具」）：
  - 展开嵌套转义：把字符串里的 JSON（含多层、整体被转义的字符串）还原为结构；「转义为字符串」反向操作。
  - 修复 / 提取 JSON：容忍注释、单引号、无引号字段、尾逗号、`undefined` / `NaN`；可从 `curl` 请求体、`fetch` 的 `body`、日志行中截取 JSON。粘贴到空编辑器或全选替换时，非法 JSON 会自动尝试修复，并可撤销。
  - 生成 TypeScript 类型 / Zod Schema：同级数组元素合并，缺失字段标为可选，`null` 并入联合类型；仅依据当前样本推断，不是完整 Schema。
  - 导出 CSV / YAML / `.env`；CSV 与表格视图取根对象中元素最多的对象数组（如 `$.data.list`），嵌套对象按 `a.b` 展开。
  - JSONPath 过滤：支持 `.key`、`[*]`、`..key`、`[n]`、`[a:b]`、`[?(@.price > 10 && @.name =~ /x/)]`，结果可点击定位，复制时保留数字原文。
  - 表格视图：排序、筛选（最多载入 5,000 行，显示 500 行）；Mock 数据：数组循环扩充到 N 条（≤ 10,000），`id` 类字段自增。
  - 历史快照：手动保存到本机 localStorage，最多 10 条（每条 ≤ 1 MB），不会自动保存或上传。
- 「键排序」：格式化时按字母排序对象字段，保留数字原文。
- 对比页「忽略字段」：逗号分隔，字段名匹配任意层级，`$` 开头为路径（数组下标可写 `[*]`），用于忽略 `timestamp`、`requestId` 等每次不同的字段；导出的差异报告会记录该设置。
- 悬停数字或字符串：10 / 13 位时间戳显示日期；JWT 显示头部与载荷（仅解码，不验证签名）；Base64 显示解码文本。长度超过 2 万字符的单行不解码。
- 复制、下载、清空和撤销。无工作空间、文档管理、示例或文件导入入口。
- 本地修改仅在内存中，刷新或关闭后清空；存在未导出更改时尝试触发浏览器离开提醒。分享链接可重新载入分享时的原文。

## 大文档设计与边界

编辑器、搜索结果和差异列表只渲染可见区域。搜索结果中的长路径自动折行，完整保留末尾字段与高亮；按实际内容计算每条结果高度，分栏或窗口尺寸变化后重新测量，支持完整复制和点击定位。缩略图使用屏幕大小的 Canvas，逐帧只读取预览窗口内的代码行；全文搜索标记聚合到屏幕像素，不生成逐行 DOM。解析、格式化、位置索引、全量搜索、结构图生成与对比在 Web Worker 中运行。自动对比一次仅处理一个任务，连续输入合并为最新一次；过期结果或错误不会覆盖新内容。

编辑器及对比模式的大文档均在输入停顿后自动处理，过期文档版本的图、搜索与路径结果不会写回。嵌套上限 512 层。

结构图默认完整展开，布局保留全部卡片与字段。React Flow 接管画布平移、滚轮缩放与节点呈现，卡片和大数组中的字段行按画布可见范围生成 DOM。普通连线使用 React Flow 自定义 SVG 边；超过 1,000 条连线时使用屏幕大小的 Canvas 绘制，避免密集连线创建海量 SVG。缩小为全图概览时以 Canvas 显示卡片轮廓，放大后恢复 React Flow 字段卡片。搜索始终覆盖全量文档，点击结果会定位具体 key，不截断数组或改变下标。重复字段在搜索中按原文位置分别显示，行号用于区分同一路径。

十万行不是固定字节数，真实速度受数据结构、字符长度和设备内存影响。浏览器仍需持有原始文档和解析树，大段粘贴/整篇替换存在主线程分配成本。

无序数组中的未匹配元素显示为删除与新增，不做相似项猜测。新建或移除的对象/数组作为一条差异显示，可点击定位完整内容。重复键允许校验和格式化，但提示其存在，并拒绝对比以避免含糊结果。

差异报告的 `beforeJSON` / `afterJSON` 是对应节点的原始 JSON 文本字符串（节点不存在时为 `null`），因此导出不会损坏大整数。
