# 任务描述

开发无广告、纯前端、中文的 JSON 格式化与结构对比工具，支持十万行 JSON 的渲染，界面美观简洁。

# 准备与分析

目录为空，无旧代码和现有约束。依赖官方文档已核实。采用 CodeMirror 可视区域渲染与 Worker 计算，格式化保留数字原文。

# 实施计划

1. 搭建工作台与文件、编辑操作。
2. 实现 Worker 校验、格式化、压缩及虚拟树。
3. 实现结构化对比、筛选、定位。
4. 验证核心行为及十万行样本，完成预览与交付。
