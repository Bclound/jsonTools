# 项目上下文

JSON 工作台是自用的纯前端中文 JSON 工具，核心功能为编辑格式化、虚拟树形查看和结构化对比。无广告、无埋点、无数据上传。视觉采用暖灰背景、白色工作区和低饱和绿色强调。

技术：原生 JavaScript、Vite、CodeMirror 6、jsonc-parser；计算放入 Web Worker，编辑区与树形/差异列表按可见区域渲染。格式化及对比保留数字原始精度，对象字段顺序不参与差异，数组默认按索引比较，可选择忽略数组顺序。文档仅保存在内存，刷新或关闭前提示未导出的更改。

性能目标：十万行 JSON 的编辑、格式化、树形和对比；真实上限受文档字节数、嵌套深度及设备内存影响。大文件按操作触发计算，避免每次输入全量解析。
