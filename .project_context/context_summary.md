# 项目上下文

公开仓库：https://github.com/Bclound/jsonTools 。在线试用：https://json-tools-alpha.vercel.app/ ，部署于 Vercel，无需登录；README 顶部提供试用入口。2026-10-15 已核对线上编辑器、结构图、格式化、大整数保留及忽略对象键序的自动对比。

自用的中文 JSON 工具（编辑与对比纯前端，主动分享使用后端存储），用户主要粘贴后端接口返回值。界面只保留编辑器与对比切换及必要操作，不展示工作空间、宣传文案、新建文档、示例或文件导入入口。默认三份内容均为空。视觉统一参考 Dracula Theme Official：#282a36 灰紫背景、粉紫强调、#191a21 深色状态栏、紧凑标签与工具栏。代码、结构图和缩略图共享 CSS 颜色变量；字段青色、字符串黄色、数值及布尔值/null 紫色，选区 #44475a、搜索命中橙色、差异新增绿色与删除红色。保持单一深色主题，无额外主题切换或依赖。

技术：原生 JavaScript、Vite、CodeMirror 6、jsonc-parser；结构图区单独挂载 React 19 与 React Flow 12；计算放入 Web Worker，编辑区与搜索/差异列表按可见区域渲染。格式化及对比保留数字原始精度，对象字段顺序不参与差异，数组默认按索引比较，可选择忽略数组顺序。文档仅保存在内存，刷新或关闭前提示未导出的更改。

性能目标：十万行 JSON 的编辑、格式化、结构图、路径搜索和对比；真实上限受文档字节数、嵌套深度及设备内存影响。对比模式在输入停顿 350 ms 后自动计算，单任务运行，过期结果和错误不写回；已解析且未变化的一侧复用解析树。编辑器同样在输入停顿后自动解析，按文档版本隔离图、搜索与光标定位结果。

三个代码区均支持单行对象/数组 JSON 左键双击格式化，多行内容双击保留原生选词、使用灰紫选区；焦点行与差异底色保持半透明，避免遮住选区。对比的两侧双向同步滚动，不等长时按比例联动；点击差异定位时短暂暂停同步，保留各侧精确位置。

编辑器是代码与结构图同屏，可调分栏。结构图默认完整展开，无分页或卡片数量限制；graph-layout.js 计算完整布局和精确字段坐标，graph-layout.js 的 flowGraph 转换为 React Flow 节点与字段连线，graph-flow.jsx 负责 React Flow 画布及自定义卡片，graph.js 保留既有 GraphView API 与精确光标定位。React Flow 开启 onlyRenderVisibleElements，卡片内字段仍按可见行渲染；普通边用自定义 SVG，超过 1,000 条边改用屏幕 Canvas，低缩放时绘制概览轮廓，避免海量 DOM。平移、滚轮缩放由 React Flow 接管，字段与卡片按钮保留点击和键盘操作。图随光标自动平移至具体 key，并展开被收起的祖先。搜索始终扫描全量数据，与图状态无关；关键词仅匹配字段名/值本身，完整路径仅精确匹配，不按祖先路径展开搜索结果；虚拟列表显示原文行号、值和含数组下标的完整路径。当前位置栏包含具体字段名（如 $.same）、一级字段、行首缩进、值末尾与逗号后位置，支持复制路径；搜索会展开代码折叠区域。特殊键名使用 JSONPath 方括号表示。没有代码/树形视图切换。

搜索结果使用搜索框下方的非模态浮层，点击结果、外部、关闭按钮或 Esc 收起；保留关键词，再次聚焦/点击搜索框展开。长路径自动折行，VirtualList 为搜索采用实测行高、前缀位置及二分查找，只渲染可见行和预加载区域；宽度变化重新测量，滚动时保持当前项或列表底部。差异列表继续采用固定行高。主编辑区右侧 CodeMinimap 使用 Canvas 绘制局部代码预览、视口滑块与命中行，右边缘显示全文搜索位置；可点击/拖动/滚轮/键盘导航及手动收起展开。minimap-core.js 提供窗口、行号和像素映射；复用搜索结果行号，文档或关键词改变时清除旧标记，不增加依赖。

结构图字段与卡片标题使用 tsType 标签。Worker 的 graphType 按当前值生成基础 TS 类型，数组聚合全部直接元素类型（去重排序）；空数组 unknown[]，内层数组按 unknown[] 概括，不展开对象声明。只在生成图数据时计算，不在图拖动或缩放时扫描 JSON。卡片宽度 340px，列距为卡片宽度加 80px；行高仍为 30px，保持可见范围渲染。标签按类型着色，长联合类型省略并以 title 展示全文，点击标签仍定位原字段。标签不是 Schema 或接口约束。

全局搜索结果携带 highlights 原文字符范围，字段名和值的多处命中同时标记，支持 JSON 转义和大小写转换的位置映射；完整路径查找标记对应字段。editor.js 在主编辑器中以 StateField 保存范围，ViewPlugin 对可见范围二分定位并生成字符高亮；当前结果以加粗橙色边框区分。收起浮层保留标记，清空关键词或编辑事务清除旧范围，避免嵌套派发事务。点击结果定位第一处实际命中的字符，保留路径/结构图联动。
