# 项目上下文

自用的纯前端中文 JSON 工具，用户主要粘贴后端接口返回值。界面只保留编辑器与对比切换及必要操作，不展示工作空间、宣传文案、新建文档、示例或文件导入入口。默认三份内容均为空。视觉采用暖灰背景、白色编辑区和低饱和绿色强调。

技术：原生 JavaScript、Vite、CodeMirror 6、jsonc-parser；计算放入 Web Worker，编辑区与搜索/差异列表按可见区域渲染。格式化及对比保留数字原始精度，对象字段顺序不参与差异，数组默认按索引比较，可选择忽略数组顺序。文档仅保存在内存，刷新或关闭前提示未导出的更改。

性能目标：十万行 JSON 的编辑、格式化、结构图、路径搜索和对比；真实上限受文档字节数、嵌套深度及设备内存影响。对比模式在输入停顿 350 ms 后自动计算，单任务运行，过期结果和错误不写回；已解析且未变化的一侧复用解析树。编辑器同样在输入停顿后自动解析，按文档版本隔离图、搜索与光标定位结果。

三个代码区均支持单行对象/数组 JSON 左键双击格式化，多行内容双击保留原生选词、使用蓝色选区；焦点行与差异底色保持半透明，避免遮住选区。对比的两侧双向同步滚动，不等长时按比例联动；点击差异定位时短暂暂停同步，保留各侧精确位置。

编辑器是代码与结构图同屏，可调分栏。结构图默认完整展开，无分页或卡片数量限制；graph-layout.js 计算完整布局和精确字段坐标，graph.js 仅生成可见卡片/字段 DOM，屏幕大小的 Canvas 绘制连线，低缩放时绘制概览轮廓。图随光标自动平移至具体 key，并展开被收起的祖先。搜索始终扫描全量数据，与图状态无关，虚拟列表显示原文行号、值和含数组下标的完整路径。当前位置栏包含具体字段名（如 $.same）、一级字段、行首缩进、值末尾与逗号后位置，支持复制路径；搜索会展开代码折叠区域。特殊键名使用 JSONPath 方括号表示。没有代码/树形视图切换。
