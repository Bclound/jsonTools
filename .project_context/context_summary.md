# 项目上下文

自用的纯前端中文 JSON 工具，用户主要粘贴后端接口返回值。界面只保留格式化与对比切换及必要操作，不展示工作空间、宣传文案、新建文档、示例或文件导入入口。默认三份内容均为空。视觉采用暖灰背景、白色编辑区和低饱和绿色强调。

技术：原生 JavaScript、Vite、CodeMirror 6、jsonc-parser；计算放入 Web Worker，编辑区与树形/差异列表按可见区域渲染。格式化及对比保留数字原始精度，对象字段顺序不参与差异，数组默认按索引比较，可选择忽略数组顺序。文档仅保存在内存，刷新或关闭前提示未导出的更改。

性能目标：十万行 JSON 的编辑、格式化、树形和对比；真实上限受文档字节数、嵌套深度及设备内存影响。对比模式在输入停顿 350 ms 后自动计算，单任务运行，过期结果和错误不写回；已解析且未变化的一侧复用解析树。编辑模式超过 250 KB 时按需解析。

三个代码区均支持左键双击格式化。对比的两侧双向同步滚动，不等长时按比例联动；点击差异定位时短暂暂停同步，保留各侧精确位置。
