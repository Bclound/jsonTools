快捷键与使用说明

JSON 工作台是免费的在线 JSON 格式化、校验、压缩与结构对比工具，无需注册或登录。编辑、搜索、格式化和对比在浏览器本地处理。

直接粘贴 JSON。单行压缩 JSON 双击左键即可格式化；多行已排版内容双击选中单词，再按 ⌘ / Ctrl + C 复制。输入或修改对比选项后，会自动更新差异；两侧滚动条同步。

对比默认忽略对象字段顺序，按数组索引匹配。忽略数组顺序时，未匹配项分别显示为删除与新增。格式化、压缩和对比保留大整数原始精度，重复字段需先消除歧义才能对比。

搜索覆盖完整文档，只匹配字段名或值本身，不因祖先路径命中而列出子项；输入完整路径可精确查找。搜索结果浮在搜索框下方，点击结果后收起；Esc、关闭按钮或点击外部可收起，再次点击搜索框可展开。结果显示路径与数组下标。代码右侧缩略图支持点击、拖动、滚轮和收起/展开；橙色标记显示搜索命中行，最右侧标记覆盖全文。点击结果或图中字段可定位代码；当前位置栏跟随光标更新，可复制路径。结构图支持拖动、缩放，全部节点默认展开，无分页。光标移动时自动定位图中的对应 key；缩小为概览时显示节点轮廓，放大后显示字段。

「工具」菜单提供转义展开、JSON 修复与提取、TypeScript 类型与 Zod Schema 生成、CSV / YAML / .env 导出、JSONPath 过滤、表格与历史快照；对比页可填写要忽略的字段。类型与 Schema 仅根据当前样本推断。

点击「分享」会上传当前 JSON 副本，生成 7 天有效的链接。持有链接的人均可访问。对方可以自由操作自己的副本，不影响原文或原链接。普通编辑、搜索和对比仍在本地完成。

关闭或刷新页面会清空未保存的内容，需要保留时请复制、下载，或手动保存历史快照到当前浏览器。
