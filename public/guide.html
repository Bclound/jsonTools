JSON 工作台使用指南

JSON 工作台是免费的在线 JSON 格式化、校验、压缩和结构对比工具，无需注册或登录。它面向需要检查接口返回值的开发者，支持大整数精度保留、可视化结构图、全局搜索、JSONPath 过滤和类型生成。

编辑、搜索、格式化和对比在浏览器本地完成。只有主动点击「分享」，才会把当前 JSON 副本上传保存 7 天。

格式化与大整数结构对比搜索与 JSONPath修复、类型与导出数据保存与分享大文档与使用边界快捷键

如何格式化 JSON，并保留大整数精度？

在编辑器中粘贴 JSON，点击「格式化」，或使用 ⌘ / Ctrl + Shift + F。缩进可选择 2、4、8 空格；「压缩」去掉排版空白，「校验」显示语法错误并定位。单行对象或数组也可双击左键格式化，多行内容双击保持选词。

JSON 工作台的格式化、压缩和结构对比保留原始数字文本。下面的 19 位整数不会在格式化时被四舍五入：

{"id":9223372036854775807,"name":"示例"}

选择 2 空格格式化后的结果：

{
  "id": 9223372036854775807,
  "name": "示例"
}

这适合检查后端返回的长整型 ID。若数字在粘贴前已经被其他程序转换并丢失精度，工具无法恢复丢失的位数；请从原始接口响应复制。勾选「键排序」可以按字母顺序排列对象字段。

如何比较两份 JSON，忽略字段顺序和时间戳？

进入「对比」，分别粘贴原始 JSON 与目标 JSON。停止输入约 350 毫秒后自动计算，按路径列出新增、删除、修改；点击结果可以定位两侧代码，并可导出完整差异报告。

结构对比默认忽略对象字段顺序。例如 {"a":1,"b":2} 与 {"b":2,"a":1} 一致。数组默认按索引比较；勾选「忽略数组顺序」后按元素匹配，仍保留重复项数量，因此 [1,1,2] 与 [1,2] 不一致。

示例：只关注业务状态变化

原始 JSON：

{"id":9223372036854775807,"status":"pending","timestamp":1700000000}

目标 JSON：

{"timestamp":1700000060,"status":"done","id":9223372036854775807}

在「忽略字段」输入 timestamp，结果只保留 $.status 从 pending 到 done 的修改。可以用逗号分隔多个字段，例如 timestamp, requestId；普通字段名匹配任意层级，以 $ 开头则按路径匹配，例如 $.data[*].traceId。

忽略数组顺序时，未匹配元素列为新增和删除，不猜测相似对象之间的对应关系。含重复键的 JSON 可以校验和格式化，但需要先消除重复键才能对比。

如何查找嵌套字段、复制路径或使用 JSONPath？

编辑器右侧显示 JSON 可视化结构图，支持平移、缩放和展开收起。点击字段可定位代码，移动代码光标会同步定位图中字段；「当前位置」栏可以复制完整路径。

顶部搜索框查找全量文档中的字段名和值，不受折叠状态限制。输入完整路径如 $.data.list[0].id 可以精确定位；带点号等特殊字符的键使用方括号，例如 $["user.name"]。

需要批量选取数据时，打开「工具 → JSONPath 过滤」。例如对下面的 JSON 使用 $.data.list[*].id，可选出两个 ID：

{"data":{"list":[{"id":101,"name":"甲"},{"id":102,"name":"乙"}]}}

全局搜索框用于关键词或完整路径定位；带通配符、切片或条件的查询放在 JSONPath 工具中。当前实现支持字段、数组索引、[*]、递归字段 ..key、切片 [a:b] 和部分条件表达式。

如何修复 JSON、生成 TypeScript 类型或导出 CSV？

编辑器「工具」菜单提供以下操作，均基于当前编辑器内容在本地运行：

展开嵌套转义 / 转义为字符串
把字符串中的 JSON 还原为结构，或反向把整份内容转成 JSON 字符串。
修复 / 提取 JSON
处理注释、单引号、无引号字段、尾逗号等输入，也可从 cURL、fetch 请求体和日志中提取 JSON。粘贴到空编辑器或全选替换时会尝试自动修复，修改可以撤销。
TypeScript 类型 / Zod Schema
根据当前样本推断类型，合并同级数组元素，缺失字段标记为可选。生成结果反映样本内容，仍需补充业务约束。
CSV / YAML / .env 导出
将数据转换并下载。CSV 选择根对象中元素最多的对象数组，如 $.data.list，嵌套字段按 a.b 展开。
表格视图 / Mock 数据
把对象数组显示为可排序筛选的表格，或按现有数据循环扩充数组，id 类字段自增。

结构图中的 TypeScript 标签只是当前值的类型概括；完整类型生成位于「工具」菜单。JWT 悬停提示仅解码头部和载荷，不验证签名。

JSON 会上传吗？刷新后还在吗？

普通编辑、搜索、格式化、校验和对比不会上传 JSON。刷新或关闭会清空内存中的修改。需要保留时，复制、下载，或主动保存历史快照。

三种数据保存方式
操作保存位置保留方式
普通编辑与对比当前页面内存刷新或关闭后清空；离开前请导出
手动历史快照当前浏览器 localStorage最多 10 条；清理站点数据会删除，不会同步到其他设备
主动分享服务端 Redis 存储保存点击分享时的副本，7 天后过期，单份最多 4 MiB

分享后，对方修改会影响我的 JSON 吗？

不会。接收方打开的是独立副本，可以编辑、格式化、搜索和对比；修改不会写回原链接，也不会影响分享者。再次分享会创建新的副本。持有链接的人均可访问分享内容，请在分享前移除口令、令牌等敏感信息。

站点是否有访问统计？

首页与使用指南使用 51LA 统计访问量，并开启事件分析和 hash 路由统计。51LA 会上报完整页面地址，包括查询参数和 hash；打开分享链接时，地址中的分享 ID 也会进入统计。

工具页的生产版本同时使用 Vercel Web Analytics。Vercel 统计不包含 JSON 原文、搜索词或分享 ID，上报前会移除 URL 查询参数和 hash。

能处理十万行 JSON 吗？有哪些使用边界？

项目已有 120,002 行样本的核心验证，编辑、搜索和差异列表只渲染可见区域，解析与对比在 Web Worker 中处理。实际速度取决于字节数、嵌套结构和设备内存，行数不是固定容量保证。

  • JSON 嵌套上限为 512 层。
  • JSONPath 最多保留 5,000 个匹配，界面列表最多展示 500 个。
  • 表格视图最多载入 5,000 行，最多展示 500 行；Mock 最多生成 10,000 条。
  • 分享的 4 MiB 上限只限制分享，不是编辑器的文档上限。
  • 浏览器需要支持 JavaScript、Web Worker 等现代 Web 功能；本页指南无需 JavaScript 即可阅读。

功能实现与验证样本可在 GitHub 项目仓库核对，问题可提交到项目 Issues。
